# Expense Tracker - Project 2

A simple Python program to track and calculate total expenses entered by the user.

## Features

- Enter expenses one by one
- Calculate total spending
- Type `quit` to finish
- Handles invalid input

## Technologies

- Python
- While Loop
- Exception Handling

```text
Enter expense amount: 100
Enter expense amount: 250
Enter expense amount: 150
Enter expense amount: quit
